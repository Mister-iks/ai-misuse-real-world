## Important interpretation notes

This repository intentionally separates source-derived observations from broader defensive interpretation.

For example, the document's conceptual model:

`Risk ≈ Capability × Access × Scale × Speed × Persistence × Intent`

is an explanatory framework created for this guide, **not a mathematical formula presented by Anthropic**.

Likewise, the AppSec checklists and defensive recommendations are practical interpretations intended to help security practitioners apply the report's lessons.
