# Source and Case Index

## Primary source

**Anthropic, Detecting and Countering Misuse of AI: September 2026**

Scope stated in the report: malicious activity observed or disrupted by Anthropic Threat Intelligence from December 2025 through August 2026.

## Report structure

The report covers seven broad areas:

1. Cyber operations
2. Influence operations
3. Surveillance operations
4. Conventional weapons
5. Biological misuse
6. Scams and fraud
7. Illicit distillation

## Interpretation notes

This repository intentionally separates source-derived observations from broader defensive interpretation.

For example, the conceptual model:

`Risk = Capability x Access x Scale x Speed x Persistence x Intent`

is an explanatory framework created for this guide. It is not a mathematical formula presented by Anthropic.

The AppSec checklists and defensive recommendations are practical interpretations intended to help security practitioners apply the report's lessons.
